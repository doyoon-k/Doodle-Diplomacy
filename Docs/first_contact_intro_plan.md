# First Contact 인트로 제작 계획

> 목표: 대통령이 차량 안에서 UFO 뉴스를 본 뒤 Zaucer Pizza를 통해 지하시설로 들어가고, 황 박사의 브리핑과 회담장 착석을 거쳐 본 게임의 외계인 번역 튜토리얼로 자연스럽게 진입하게 한다.

## 제작 원칙

- 인트로는 퍼즐이 아니라 **현장에 들어온 느낌을 주는 짧은 인터랙티브 컷씬**이다.
- 플레이어가 하는 핵심 행동은 국장을 따라 걷기, 엘리베이터에 탑승하기, 지정 좌석에 앉기 세 가지면 충분하다.
- 긴 단일 Timeline보다, 장소와 목적이 분명한 짧은 연출 구간으로 분리한다.
- 인트로 전체를 플레이스홀더로 처음부터 끝까지 연결한 뒤 환경·캐릭터·음성을 고도화한다.
- 수동으로 맞춘 카메라 Shot, 플레이어 시작 위치, 문·모니터의 Transform은 보존한다. **씬을 자동으로 재생성하거나 재빌드하는 도구를 사용하지 않는다.**
- 문, 엘리베이터, 보안문은 시점 전환과 Additive 씬 로딩을 숨기는 장치로 사용한다.

## 씬 구조

```text
GameRoot
├─ FC_Intro_Surface
│  ├─ 차량 내부와 TV 뉴스
│  ├─ 주차장과 Zaucer Pizza 외관
│  ├─ 피자집 홀 / 주방 / 창고
│  └─ 비밀문과 엘리베이터 입구
│
├─ FC_Intro_Facility
│  ├─ 엘리베이터 출구
│  ├─ 지하 L자 복도
│  └─ 브리핑실과 보안 복도
│
└─ GameScene
   ├─ 회담장 진입 복도
   ├─ 회담장
   └─ 외계인, 터미널, 본 게임 튜토리얼
```

초기에는 엘리베이터와 보안문에서 짧은 페이드로 전환한다. 이후에는 문이 닫힌 동안 다음 씬을 비동기로 Additive 로드한다. 기존 `GameFlowDirector`와 `InteractiveCutscene` Flow Entry를 우선 활용한다.

## 현재 구현 상태

### 차량 TV 뉴스

- 재생 순서: `UFO_VHS` → 리포터 → 목격자 인터뷰 → 같은 레드먼드 UFO의 기록 사진 → 공군 브리핑 → TV 전원 종료.
- 영상의 원본 오디오는 재생하지 않는다.
- TV 내부에는 1980년대 방송 하단바와 CRT/VHS 효과를 적용한다.
- 방송 그래픽 문구는 영어 원문으로 유지한다.
- 뉴스 재생 중 카메라는 사용자가 배치한 TV Shot에 고정되고, 중앙 크로스헤어는 숨긴다.
- 뉴스 종료 시 카메라는 다음 시점으로 부드럽게 블렌드한다.
- 영상 초기 준비 실패 시 재시도하여 첫 `UFO_VHS`가 건너뛰지 않도록 처리한다.
- 뉴스 종료 후 대통령·국장 대사 3개를 자동 재생하고, 플레이어 위치를 유지한 채 실제 Zaucer Pizza 간판 방향으로 잠시 시선을 유도한다. 기존 `SHOT_Pizza_Sign`은 카메라 이동용 위치가 아니라 참고용 Shot으로만 유지한다.
- 간판 대사 2개가 끝나면 차량 시점으로 돌아오며 문손잡이 상호작용이 활성화된다.

### 읽기 쉬운 뉴스 대사

- TV의 노이즈가 강한 하단바와 별개로, 화면 하단 HUD에 화자명과 대사를 선명하게 표시한다.
- 이 패널은 TV 재질 안에 들어가는 요소가 아니라 게임 화면의 오버레이 UI다. TV가 화면을 크게 차지하므로 시각적으로는 TV 하단에 겹쳐 보일 수 있다.
- 뉴스 대사는 Narrative Desk의 `first_contact_day1 > In-car news broadcast` 섹션에서 수정한다.
- 각 비트는 영어 원문, 한국어 번역, 화자명, 최소 표시 시간을 가진다.

### Narrative Desk

- Unity 메뉴 `Tools > Narrative Desk > Open Narrative Desk`로 실행한다.
- 로컬 주소: `http://127.0.0.1:4317`.
- Narrative Desk에서 저장한 뉴스 대사는 생성된 내러티브 에셋과 로컬라이제이션 테이블에 동기화된다.

## 맵 그레이박스 기준

```text
[차량 내부]
   ↓ 정차 / 컷
[주차장 + 피자집 전면]
   ↓
[식당 홀] ─ 시민 테이블
   ↓
[주방]
   ↓
[창고] ─ 선반 / 비밀문
   ↓
[엘리베이터]
   ↓ 씬 전환
[지하 L자 복도] ─ 기록물 / UFO 사진
   ↓
[브리핑실]
   ↓
[보안 복도 / 에어록]
   ↓ 씬 전환
[회담장]
```

Unity 1유닛 = 1m 기준의 권장 크기:

- 식당 홀: 12 × 16m
- 주방: 8 × 10m
- 창고: 6 × 7m
- 엘리베이터: 3 × 3m
- 지하 복도: 폭 2.5~3m, 총 길이 25~35m
- 브리핑실: 10 × 12m
- 회담장: 12 × 16m

지하 복도는 L자 형태로 구성한다. 다음 공간을 미리 보여주지 않고, NPC 이동과 씬 로딩을 자연스럽게 숨길 수 있다.

## 아트 방향과 필요한 환경 에셋

### 차량·외부

- 대통령 전용 SUV 또는 리무진 내부 세트
- 차량 모니터, 문손잡이, 창밖 이동 배경
- Zaucer Pizza 외관, 발광 간판, 소규모 주차장, 가로등, 주변 건물 실루엣

실제 차량 주행은 구현하지 않는다. 차량 내부 독립 세트와 움직이는 창밖 배경으로 충분하다.

### 피자집

- 홀 벽·바닥·천장 모듈, 테이블, 의자, 부스 좌석
- 카운터, 메뉴판, 계산대, 피자 상자, 컵, 접시, 냅킨
- 주방 오븐, 냉장고, 작업대, 싱크대
- 창고 선반, 상자, 식재료 포대
- 이동 선반과 벽문으로 구성된 비밀문

피자집은 따뜻한 적색·주황 조명으로, 지하시설은 청록·회색 조명으로 구분한다. 비밀문이 열리는 순간 색과 분위기가 명확히 전환되어야 한다.

### 지하시설·회담장

- 산업용 엘리베이터, 지하 복도 모듈, 보안문, 배관, 환풍구, 천장 조명
- 외계인 목격 보고서, UFO 사진, 분석 도표
- 브리핑 테이블·의자, 빔 프로젝터와 스크린, 컴퓨터·계측 장비
- 회담장 보안문, 관찰창, 터미널과 외계인 배치

기존 SciFi Warehouse Kit은 지하시설 그레이박스에 우선 재활용한다.

## 캐릭터와 애니메이션

### 우선 캐릭터

1. 국장
2. 닥터 황
3. 오바마
4. 피자집 시민 4종
5. 연구원·관료 4종

대통령은 1인칭이므로 풀바디 모델을 우선 제작할 필요가 없다. 필요해질 때 1인칭 팔과 손 애니메이션만 추가한다. TV 속 리포터·목격자·공군 장성은 게임 공간에 나오지 않으므로 영상으로 처리한다.

### 필수 애니메이션

- 공통: 대기, 걷기, 앉기, 일어서기, 고개 돌리기, 대화 제스처, 시선 추적
- 시민: 대통령을 바라보기, 단체 웃음
- 국장: 선반 이동, 벽 두드리기, 엘리베이터 버튼 누르기
- 황 박사: 리모컨 누르기, 헛기침, 빠르게 설명하기
- 오바마: 커피를 내려놓기
- 장치: 비밀문·엘리베이터·보안문 개폐

정교한 립싱크보다 시선, 손동작, 타이밍이 우선이다.

## 브리핑 슬라이드 계획

황 박사 브리핑은 약 10~12장의 슬라이드로 구성한다.

1. 복잡한 뇌파·수식 화면
2. 사물을 볼 때 발생하는 뇌 신호
3. 바나나와 대응 파형
4. 모든 사물을 수집할 수 없는 문제
5. 사과와 바나나가 같은 음식 CATEGORY에 속하는 예시
6. 유사 파형이 그룹을 이루는 모습
7. 미수집 단어를 자동 해석하는 과정
8. 소 납치 기록
9. 미스터리 서클 기록
10. 군사시설 인근 UFO 관측
11. 위험 / 보호 / 음식 / 도구 CATEGORY
12. 대통령 영상에 외계인이 반응한 계측 결과

목표는 과학적 정확성보다 “복잡한 설명 → 대통령과 국장이 못 알아들음 → 그림으로 쉽게 설명”이라는 코미디 리듬이다.

## 오디오 계획

필요한 주요 화자:

- 대통령, 국장, 닥터 황, 오바마
- 리포터, 목격 시민, 공군 장성
- 피자집 시민

필수 효과음:

- 차량 주행음, TV 노이즈·전원음
- 식당 웅성거림·단체 웃음, 주방 접시·오븐 소리
- 벽 두드림, 비밀문 기계음, 엘리베이터 이동·도착음
- 지하시설 환풍기·전기음, 프로젝터 팬·슬라이드 전환음
- 문, 의자, 커피잔, 바닥별 발소리

배경음악은 차량의 불안감, 피자집의 코미디, 지하시설의 긴장감 세 큐로 시작한다.

## 시스템과 로직

### 인트로 진행

- `FirstContactIntroSequenceController`를 구간 진행의 중심으로 사용한다.
- 구간별로 대사, NPC 행동, 문 상태, 목표 텍스트, 카메라, 상호작용 잠금을 연결한다.
- `runtimeCue` 및 `triggerEvent`를 실제 연출과 연결한다.
- 디버그 시 현재 구간으로 이동하거나 다음 비트를 실행할 수 있어야 한다.

권장 구간 이름:

```text
CarNews
CarExit
PizzaArrival
RestaurantEncounter
SecretDoorReveal
ElevatorDescent
FacilityWalk
Briefing
ObamaEntrance
```

### 플레이어·NPC

- 이동, 시선, 상호작용 입력을 독립적으로 잠글 수 있어야 한다.
- 국장은 목적지까지 이동하고 플레이어가 멀어지면 기다린다.
- 트리거 볼륨으로 따라가기 완료, 엘리베이터 탑승, 좌석 착석을 판정한다.
- 컷씬 종료 후 플레이어 위치와 시점을 안전하게 복원한다.
- NPC 이동은 NavMesh를 사용하되, 짧은 연출은 지정 waypoint 기반 이동으로도 충분하다.

### 공간 장치

- 비밀문: 선반 상태, 노크, 벽문 개방의 상태 머신
- 엘리베이터: 호출, 탑승 판정, 문 닫힘, 하강, 도착, 씬 전환
- 브리핑: 슬라이드 전환과 대사 비트 연결
- 회담장: 보안문, 지정 좌석, 외계인 입장 직전의 제어 잠금

### 체크포인트·접근성

권장 체크포인트:

1. 차량 뉴스 종료
2. 엘리베이터 도착
3. 브리핑 시작
4. 브리핑 종료
5. 회담장 착석

추가 고려 사항:

- 자동 진행과 클릭 진행을 대사별로 선택 가능하게 유지
- 자막 크기·배경·화자명 설정
- 구간별 순간이동 디버그 메뉴
- 현재 비트와 대기 조건을 보여주는 디버그 패널

## 제작 순서

### 1단계 — 전체 그레이박스 연결

- 모든 공간을 기존 에셋과 큐브로 구성
- 차량에서 회담장까지 실제로 이동 가능하게 만들기
- 문, 엘리베이터, 착석 상호작용 구현
- 임시 자막과 대사로 전체 흐름 재생
- 씬 전환과 체크포인트 연결

### 2단계 — 연출 프로토타입

- 차량 뉴스, 피자집 반응, 비밀문, 엘리베이터, 브리핑, 오바마 등장 구현
- NPC 캡슐과 임시 애니메이션, 카메라 블렌드, 브리핑 슬라이드 적용
- 플레이어 제어 잠금·복원과 목표 텍스트 점검

### 3단계 — 환경·캐릭터 제작

- 국장과 황 박사 우선 제작
- 피자집·비밀문 환경 완성
- 지하시설 환경 아트와 시민·연구원 변형 추가

### 4단계 — 오디오와 폴리시

## 다음 작업

현재 TV 뉴스와 Narrative Desk 기반 뉴스 자막, **TV 종료 → 대통령·국장 대화 → Zaucer Pizza 간판 → 차량 하차 활성화** 구간은 구현되어 있다. 다음 우선 작업은 **차량 하차 → Zaucer Pizza 입장 → 시민 반응**을 하나의 완성된 플레이 구간으로 연결하는 것이다.
