# First Contact 인트로 제작 계획

> 목표: 대통령이 차량 안에서 UFO 뉴스를 본 뒤 Zaucer Pizza를 통해 지하시설로 들어가고, 황 박사의 브리핑과 회담장 착석을 거쳐 본 게임의 외계인 번역 튜토리얼로 자연스럽게 진입하게 한다.

## 제작 원칙

- 인트로는 퍼즐이 아니라 **현장에 들어온 느낌을 주는 짧은 인터랙티브 컷씬**이다.
- 플레이어가 하는 핵심 행동은 국장을 따라 걷기, 엘리베이터에 탑승하기, 지정 좌석에 앉기 세 가지면 충분하다.
- 긴 단일 Timeline보다, 장소와 목적이 분명한 짧은 연출 구간으로 분리한다.
- 인트로 전체를 플레이스홀더로 처음부터 끝까지 연결한 뒤 환경·캐릭터·음성을 고도화한다.
- 수동으로 맞춘 카메라 Shot, 플레이어 시작 위치, 문·모니터의 Transform은 보존한다. **씬을 자동으로 재생성하거나 재빌드하는 도구를 사용하지 않는다.**
- 문, 엘리베이터, 보안문은 시점 전환과 Additive 씬 로딩을 숨기는 장치로 사용한다.

## 씬 구조

```text
GameRoot
├─ FC_Intro_Surface
│  ├─ 차량 내부와 TV 뉴스
│  ├─ 주차장과 Zaucer Pizza 외관
│  ├─ 피자집 홀 / 주방 / 창고
│  └─ 비밀문과 엘리베이터 입구
│
├─ FC_Intro_Facility
│  ├─ 엘리베이터 출구
│  ├─ 지하 L자 복도
│  └─ 브리핑실과 보안 복도
│
└─ GameScene
   ├─ 회담장 진입 복도
   ├─ 회담장
   └─ 외계인, 터미널, 본 게임 튜토리얼
```

초기에는 엘리베이터와 보안문에서 짧은 페이드로 전환한다. 이후에는 문이 닫힌 동안 다음 씬을 비동기로 Additive 로드한다. 기존 `GameFlowDirector`와 `InteractiveCutscene` Flow Entry를 우선 활용한다.

## 현재 구현 상태

### 차량 TV 뉴스

- 재생 순서: `UFO_VHS` → 리포터 → 목격자 인터뷰 → 같은 레드먼드 UFO의 기록 사진 → 공군 브리핑 → TV 전원 종료.
- 영상의 원본 오디오는 재생하지 않는다.
- TV 내부에는 1980년대 방송 하단바와 CRT/VHS 효과를 적용한다.
- 방송 그래픽 문구는 영어 원문으로 유지한다.
- 뉴스 재생 중 카메라는 사용자가 배치한 TV Shot에 고정되고, 중앙 크로스헤어는 숨긴다.
- 뉴스 종료 시 카메라는 다음 시점으로 부드럽게 블렌드한다.
- 영상 초기 준비 실패 시 재시도하여 첫 `UFO_VHS`가 건너뛰지 않도록 처리한다.
- 뉴스 종료 후 대통령·국장 대사 3개를 자동 재생하고, 플레이어 위치를 유지한 채 실제 Zaucer Pizza 간판 방향으로 잠시 시선을 유도한다. 기존 `SHOT_Pizza_Sign`은 카메라 이동용 위치가 아니라 참고용 Shot으로만 유지한다.
- 간판 대사 2개가 끝나면 차량 시점으로 돌아오며 문손잡이 상호작용이 활성화된다.

### 차량 연속 주행 그레이박스

- Surface 구간은 **하나의 연속된 월드**다. 기존 `PizzaExterior_Graybox`와 실내는 처음부터 끝까지 같은 위치에서 활성 상태로 유지하며, 피자집 복제·맵 숨김·도착 시 세트 교체를 사용하지 않는다.
- `FirstContactVehicleRouteController`는 기존 피자집 앞에 배치된 차량 위치를 경로 종점으로 삼는다. 그 위치로 이어지는 직선 도로, 약 90도 우회전 구간, 최종 진입로와 주차장 연결부만 런타임 그레이박스로 만든다.
- 실제 `Car`, 플레이어, 차내 모니터, 문손잡이, TV/대통령 시점 Shot을 `VehicleRoot_Runtime` 아래에 원래 월드 배치를 보존한 채 임시로 묶는다. 이후 외부 배경이 아니라 이 차량 루트 전체가 경로를 따라 이동한다.
- 뉴스 콘텐츠가 실제로 재생되는 동안에는 직선 도로를 `cruiseSpeed`의 일정 속도로 주행한다. 영상 디코더 준비·시작·종료 오버헤드처럼 기기마다 달라지는 대기 시간에는 TV 클로즈업을 유지한 채 경로 진행 시계만 잠시 멈춘다. 뉴스가 끝난 뒤 대통령과 국장이 대화하는 동안에는 다시 같은 속도로 계속 주행하며 플레이어는 마우스로 차 안을 둘러볼 수 있다.
- 국장의 `CarAfterNewsDirectorArrival` 런타임 큐는 “이제 거의 다 왔습니다” 역할의 마지막 대사에 둔다. 해당 대사가 끝나면 약 2초 동안 현재 속도로 더 직진한 뒤 코너로 진입한다. 피자집은 실제 월드 위치에 있으므로 회전하기 전에는 시야 밖에 있고, 회전하면서 간판과 주차장 조명이 자연스럽게 드러난다.
- 최종 접근이 끝나면 차량은 씬에서 사용자가 배치한 원래 주차 위치와 회전값에 정확히 정차한다. 차 안에서 본 피자집과 하차 후 걸어 들어가는 피자집은 동일한 오브젝트다.
- 문손잡이 상호작용 시 플레이어만 차량 루트에서 분리하고, 문손잡이 바깥 약 1m 지점으로 0.85초 동안 짧게 이동시킨다. 피자집 입구나 별도 맵으로 순간이동하지 않는다.
- 런타임 도로와 임시 차량 부모는 `HideFlags.DontSave`를 사용한다. Play Mode 종료 시 원래 부모 관계와 주차 Transform을 복원하므로 사용자가 조정한 TV Shot·플레이어·문손잡이·모니터 배치를 씬에 덮어쓰지 않는다.
- 직선 길이는 고정값이나 남은 시간에 따른 속도 보정에 의존하지 않는다. 뉴스 콘텐츠 길이, TV 종료 카메라 블렌드, 뉴스 후 대기, `CarAfterNewsDirectorArrival` 비트까지의 모든 `minimumSeconds`, 마지막 대사 후 회전 지연을 합산한 뒤 `총시간 × cruiseSpeed`로 런타임에 자동 계산한다. Narrative Desk에서 회전 전 대사를 추가하거나 표시 시간을 늘리면 주행 속도는 그대로이고 도로와 나무 배치만 함께 연장된다.
- 기본 조정값은 `FirstContactVehicleRouteController`의 Route Timing, Motion Feedback, Graybox Route 항목에 모여 있다. `straightStartDistance`의 `380m`는 자동 계획을 사용할 수 없을 때만 쓰는 예비값이다. 우회전은 약 `4.2초` 동안 5차 베지어 경로를 따라 이동하며, 직선과 만나는 양 끝에서 조향 곡률이 0이 되도록 구성해 방향이 갑자기 꺾이지 않는다. 우선 조정 대상은 `cruiseSpeed`, `turnRadius`, `turnSeconds`, `finalApproachDistance`, `approachSpeed`, `brakingDistance`, `brakingSeconds`다.
- 최종 환경 에셋이 준비되면 경로 상태 머신과 실제 차량 이동 구조는 유지하고, 런타임 프리미티브 도로·나무·가로등만 씬 배치 프리팹이나 전용 환경 에셋으로 교체한다.

### 피자집 입장과 시민 반응

- 차량 안에 사용자가 배치한 `Environment/Car/Adjutant`가 도착 시 직접 차에서 내린다. 플레이어가 문손잡이로 하차하면 이 국장이 현재 차 위치에서부터 `SurfaceEntry_Parking → PizzaDoor → Dining → Kitchen → Storage → Elevator` 경로를 따라 걷는다. 첫 경로 지점으로 순간이동하지 않으며, 별도 맵이나 컷 전환 없이 같은 Surface 월드에서 플레이가 이어진다.
- 피자집 쪽에 있던 `Characters_Placeholders/Director_Adjutant` 복제 오브젝트는 Surface 씬에서 완전히 제거했다. 비활성 복제본을 남기지 않고 차 안 국장 한 개체만 전체 Surface 동선에 사용한다.
- `Man_In_Suit.fbx`의 시각적 전방 축은 이동 루트의 Unity `+Z` 전방과 90도 어긋나 있으므로, 하차가 시작될 때 `AdjutantVisual`에만 Y축 `+90°` 보정을 적용한다. 이동 루트와 차내 저작 Transform은 변경하지 않으며 시퀀스 중단 시 시각 회전을 원래 값으로 복원한다.
- 국장은 기존 `Route_02_Dining` 지점에서 자동으로 멈춘다. 플레이어가 약 `3.25m` 안으로 들어오기 전까지 기다리므로 플레이어가 뒤처진 상태에서 대화가 먼저 시작되지 않는다.
- 시민 플레이스홀더 4명은 대화 시작 전에 플레이어 방향으로 부드럽게 회전한다. 국장은 자신과 가장 가까운 시민 화자를 바라보므로 외계인 농담을 대통령 쪽에 대고 말하지 않는다.
- 시민 대화 중에는 플레이어 이동과 상호작용만 잠기고 마우스 시점은 유지된다. 카메라 Shot으로 강제 전환하지 않는다.
- 시민 앞에서는 시민 질문 → 국장의 외계인 농담 → **무자막 어색한 정적** → 시민들의 웃음 → 대통령의 위장 설명 → 시민 인사 순서로 재생한다. 정적 비트가 시작되면 시민들이 국장을 다시 바라보고, 국장 대사 자막을 지운 채 잠시 침묵한 뒤 웃음으로 넘어간다.
- 정적 길이는 Narrative Desk의 `pizza_awkward_silence` 비트에 있는 `minimumSeconds`로 조절한다. 기본값은 `2.2초`이며 `sourceText`는 편집기에서 연출 의도를 설명하기 위한 메모일 뿐 게임 화면에는 표시하지 않는다.
- 시민 인사가 끝나면 국장의 경로 정차가 해제되고 플레이어 이동이 복구된다. 국장과 플레이어가 모든 시민에게서 각각 `6m` 이상 떨어져 주방 쪽으로 이동한 뒤에야 대통령의 “미쳤군.” → 국장의 “아무도 안 믿는다니까요?” 2개 비트가 재생된다. 이 사적인 대화 동안에는 이동을 잠그지 않는다.

### 읽기 쉬운 뉴스 대사

- TV의 노이즈가 강한 하단바와 별개로, 화면 하단 HUD에 화자명과 대사를 선명하게 표시한다.
- 이 패널은 TV 재질 안에 들어가는 요소가 아니라 게임 화면의 오버레이 UI다. TV가 화면을 크게 차지하므로 시각적으로는 TV 하단에 겹쳐 보일 수 있다.
- 뉴스 대사는 Narrative Desk의 `first_contact_day1 > In-car news broadcast` 섹션에서 수정한다.
- 각 비트는 영어 원문, 한국어 번역, 화자명, 최소 표시 시간을 가진다.

### Narrative Desk

- Unity 메뉴 `Tools > Narrative Desk > Open Narrative Desk`로 실행한다.
- 로컬 주소: `http://127.0.0.1:4317`.
- Narrative Desk에서 저장한 뉴스 대사는 생성된 내러티브 에셋과 로컬라이제이션 테이블에 동기화된다.
- 차량 대사는 `first_contact_day1 > car_arrival` 섹션에서 추가·복제·정렬한다. 우회전 전에 재생할 비트는 `triggerEvent`를 `intro.car.after_news`로 설정한다.
- 피자집 대사는 `first_contact_day1 > Pizza restaurant` 섹션에서 수정한다. 시민 앞의 대사와 `pizza_awkward_silence` 연출 비트는 `intro.pizza.citizen_encounter`, 시민에게서 멀어진 뒤의 마지막 2개 비트는 `intro.pizza.private_exchange` 이벤트로 재생된다.
- `CarAfterNewsDirectorArrival` 실행 큐는 우회전 직전의 마지막 국장 대사 하나에만 둔다. 런타임은 이 비트가 끝난 시점부터 약 2초 뒤 우회전을 시작한다.
- `FirstContactIntroSequenceController` Inspector의 Car Conversation Timing에서 `Post News Dialogue Delay Seconds`, `Turn Delay After Arrival Line Seconds`를 조정할 수 있다. 영상 준비 시간은 가변 런타임 대기이므로 수동 여유값을 두지 않는다.

## 맵 그레이박스 기준

```text
[직선 도로 위 실제 차량]
   ↓ 우회전 / 감속 / 같은 월드에서 정차
[기존 주차장 + 피자집 전면]
   ↓
[식당 홀] ─ 시민 테이블
   ↓
[주방]
   ↓
[창고] ─ 선반 / 비밀문
   ↓
[엘리베이터]
   ↓ 씬 전환
[지하 L자 복도] ─ 기록물 / UFO 사진
   ↓
[브리핑실]
   ↓
[보안 복도 / 에어록]
   ↓ 씬 전환
[회담장]
```

Unity 1유닛 = 1m 기준의 권장 크기:

- 식당 홀: 12 × 16m
- 주방: 8 × 10m
- 창고: 6 × 7m
- 엘리베이터: 3 × 3m
- 지하 복도: 폭 2.5~3m, 총 길이 25~35m
- 브리핑실: 10 × 12m
- 회담장: 12 × 16m

지하 복도는 L자 형태로 구성한다. 다음 공간을 미리 보여주지 않고, NPC 이동과 씬 로딩을 자연스럽게 숨길 수 있다.

## 아트 방향과 필요한 환경 에셋

### 차량·외부

- 대통령 전용 SUV 또는 리무진 내부 세트
- 차량 모니터, 문손잡이, 창밖 이동 배경
- Zaucer Pizza 외관, 발광 간판, 소규모 주차장, 가로등, 주변 건물 실루엣

Rigidbody 기반 운전 시뮬레이션은 사용하지 않는다. 차량과 차내 구성물을 묶은 루트를 저작된 경로로 이동시키는 키네마틱 연출 방식을 사용한다.

### 피자집

- 홀 벽·바닥·천장 모듈, 테이블, 의자, 부스 좌석
- 카운터, 메뉴판, 계산대, 피자 상자, 컵, 접시, 냅킨
- 주방 오븐, 냉장고, 작업대, 싱크대
- 창고 선반, 상자, 식재료 포대
- 이동 선반과 벽문으로 구성된 비밀문

피자집은 따뜻한 적색·주황 조명으로, 지하시설은 청록·회색 조명으로 구분한다. 비밀문이 열리는 순간 색과 분위기가 명확히 전환되어야 한다.

### 지하시설·회담장

- 산업용 엘리베이터, 지하 복도 모듈, 보안문, 배관, 환풍구, 천장 조명
- 외계인 목격 보고서, UFO 사진, 분석 도표
- 브리핑 테이블·의자, 빔 프로젝터와 스크린, 컴퓨터·계측 장비
- 회담장 보안문, 관찰창, 터미널과 외계인 배치

기존 SciFi Warehouse Kit은 지하시설 그레이박스에 우선 재활용한다.

## 캐릭터와 애니메이션

### 우선 캐릭터

1. 국장
2. 닥터 황
3. 오바마
4. 피자집 시민 4종
5. 연구원·관료 4종

대통령은 1인칭이므로 풀바디 모델을 우선 제작할 필요가 없다. 필요해질 때 1인칭 팔과 손 애니메이션만 추가한다. TV 속 리포터·목격자·공군 장성은 게임 공간에 나오지 않으므로 영상으로 처리한다.

### 필수 애니메이션

- 공통: 대기, 걷기, 앉기, 일어서기, 고개 돌리기, 대화 제스처, 시선 추적
- 시민: 대통령을 바라보기, 단체 웃음
- 국장: 선반 이동, 벽 두드리기, 엘리베이터 버튼 누르기
- 황 박사: 리모컨 누르기, 헛기침, 빠르게 설명하기
- 오바마: 커피를 내려놓기
- 장치: 비밀문·엘리베이터·보안문 개폐

정교한 립싱크보다 시선, 손동작, 타이밍이 우선이다.

## 브리핑 슬라이드 계획

황 박사 브리핑은 약 10~12장의 슬라이드로 구성한다.

1. 복잡한 뇌파·수식 화면
2. 사물을 볼 때 발생하는 뇌 신호
3. 바나나와 대응 파형
4. 모든 사물을 수집할 수 없는 문제
5. 사과와 바나나가 같은 음식 CATEGORY에 속하는 예시
6. 유사 파형이 그룹을 이루는 모습
7. 미수집 단어를 자동 해석하는 과정
8. 소 납치 기록
9. 미스터리 서클 기록
10. 군사시설 인근 UFO 관측
11. 위험 / 보호 / 음식 / 도구 CATEGORY
12. 대통령 영상에 외계인이 반응한 계측 결과

목표는 과학적 정확성보다 “복잡한 설명 → 대통령과 국장이 못 알아들음 → 그림으로 쉽게 설명”이라는 코미디 리듬이다.

## 오디오 계획

필요한 주요 화자:

- 대통령, 국장, 닥터 황, 오바마
- 리포터, 목격 시민, 공군 장성
- 피자집 시민

필수 효과음:

- 차량 주행음, TV 노이즈·전원음
- 식당 웅성거림·단체 웃음, 주방 접시·오븐 소리
- 벽 두드림, 비밀문 기계음, 엘리베이터 이동·도착음
- 지하시설 환풍기·전기음, 프로젝터 팬·슬라이드 전환음
- 문, 의자, 커피잔, 바닥별 발소리

배경음악은 차량의 불안감, 피자집의 코미디, 지하시설의 긴장감 세 큐로 시작한다.

## 시스템과 로직

### 인트로 진행

- `FirstContactIntroSequenceController`를 구간 진행의 중심으로 사용한다.
- 구간별로 대사, NPC 행동, 문 상태, 목표 텍스트, 카메라, 상호작용 잠금을 연결한다.
- `runtimeCue` 및 `triggerEvent`를 실제 연출과 연결한다.
- 디버그 시 현재 구간으로 이동하거나 다음 비트를 실행할 수 있어야 한다.

권장 구간 이름:

```text
CarNews
CarExit
PizzaArrival
RestaurantEncounter
SecretDoorReveal
ElevatorDescent
FacilityWalk
Briefing
ObamaEntrance
```

### 플레이어·NPC

- 이동, 시선, 상호작용 입력을 독립적으로 잠글 수 있어야 한다.
- 국장은 목적지까지 이동하고 플레이어가 멀어지면 기다린다.
- 트리거 볼륨으로 따라가기 완료, 엘리베이터 탑승, 좌석 착석을 판정한다.
- 컷씬 종료 후 플레이어 위치와 시점을 안전하게 복원한다.
- NPC 이동은 NavMesh를 사용하되, 짧은 연출은 지정 waypoint 기반 이동으로도 충분하다.

### 공간 장치

- 비밀문: 선반 상태, 노크, 벽문 개방의 상태 머신
- 엘리베이터: 호출, 탑승 판정, 문 닫힘, 하강, 도착, 씬 전환
- 브리핑: 슬라이드 전환과 대사 비트 연결
- 회담장: 보안문, 지정 좌석, 외계인 입장 직전의 제어 잠금

### 체크포인트·접근성

권장 체크포인트:

1. 차량 뉴스 종료
2. 엘리베이터 도착
3. 브리핑 시작
4. 브리핑 종료
5. 회담장 착석

추가 고려 사항:

- 자동 진행과 클릭 진행을 대사별로 선택 가능하게 유지
- 자막 크기·배경·화자명 설정
- 구간별 순간이동 디버그 메뉴
- 현재 비트와 대기 조건을 보여주는 디버그 패널

## 제작 순서

### 1단계 — 전체 그레이박스 연결

- 모든 공간을 기존 에셋과 큐브로 구성
- 차량에서 회담장까지 실제로 이동 가능하게 만들기
- 문, 엘리베이터, 착석 상호작용 구현
- 임시 자막과 대사로 전체 흐름 재생
- 씬 전환과 체크포인트 연결

### 2단계 — 연출 프로토타입

- 차량 뉴스, 피자집 반응, 비밀문, 엘리베이터, 브리핑, 오바마 등장 구현
- NPC 캡슐과 임시 애니메이션, 카메라 블렌드, 브리핑 슬라이드 적용
- 플레이어 제어 잠금·복원과 목표 텍스트 점검

### 3단계 — 환경·캐릭터 제작

- 국장과 황 박사 우선 제작
- 피자집·비밀문 환경 완성
- 지하시설 환경 아트와 시민·연구원 변형 추가

### 4단계 — 오디오와 폴리시

- 최종 음성, 환경음, 효과음, 배경음악 적용
- 시선·제스처·조명·포스트프로세싱 보강
- 자막 타이밍과 카메라 블렌드 조정

## 다음 작업

현재 **직선 주행 → TV 뉴스 → 대통령·국장 대화 → 우회전·정차 → 차량 하차 → Zaucer Pizza 입장 → 시민 반응 → 국장 재출발** 구간까지 하나의 플레이 흐름으로 구현되어 있다. 다음 우선 작업은 **주방 통과 → 창고 진입 → 선반 이동 → 비밀문 공개 → 엘리베이터 탑승**을 연출 가능한 수직 슬라이스로 만드는 것이다.

완료 기준:

1. 국장이 플레이어 속도에 맞춰 주방과 창고까지 이동한다.
2. 창고 도착 시 국장이 멈추고 대통령의 질문 대사를 재생한다.
3. 선반이 이동하고 숨겨진 벽이 열리는 연출을 재생한다.
4. 엘리베이터 내부로 실제 통과 가능한 입구가 확보된다.
5. 플레이어가 엘리베이터에 탑승하면 Surface 구간을 완료한다.

그 뒤에는 지하시설 → 브리핑 → 회담장 순서로 같은 방식의 짧은 수직 슬라이스를 확장한다.
